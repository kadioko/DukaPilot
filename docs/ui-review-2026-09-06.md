# UI review: 6 September 2026

Scope: live admin subscriptions visual review, billing/pricing/help/AppShell source
review and local payment-path checks. This is not an exhaustive review of every
authenticated merchant screen or an accessibility certification.

## Keep

Keep retail as the primary workflow. Category-specific food/farm navigation and
permission-aware staff tools prevent optional modules overwhelming ordinary shops.
Keep green action styling, familiar language controls and clear TZS amounts.

## Priorities

1. Admin subscriptions: replace repeated full renewal forms plus duplicate table
   with one paginated list and a shop details drawer. Preserve search and filters.
   Separate payment recording, free access grants and suspension in that drawer.
   Source: frontend/src/app/admin/page.tsx; confirmed visually on live admin.
2. Billing: two payment paths, one plan choice, explicit pending/confirmed states,
   and copyable network numbers. Initial loading must not say expired. This change
   introduces those basics; simplify the remaining duplicate expiry prose next.
3. Use consistent compact headings, labels and 44px touch targets. Manual network
   rows should have native selected-state semantics, not color alone. Translate
   remaining technical status labels and mixed English/Swahili billing copy.
4. Reduce colored panels nested inside panels. Use quiet sections, tables for
   comparison and a single prominent command for each task. The live admin renewal
   view currently gives many competing buttons roughly equal visual weight.
5. Keep broad page redesign separate from payment activation work. Next review
   should cover actual merchant dashboard/POS/inventory on 360px and desktop,
   using a demo account and without mutating live customer records.

## Separate logic finding

The live admin subscription badges showed totals that did not match the visible
expired rows. Investigate counts versus pagination/filter scope before relying on
those badges operationally; this review did not change the admin queries.
