# DukaPilot Brand Assets

Use the public URLs below when a partner, directory, press page, social platform, or integration asks for the DukaPilot logo.

## Official Public Logo URLs

Recommended PNG for most websites and platform forms:

`https://www.dukapilot.com/brand/dukapilot-logo.png`

Vector SVG for websites, presentations, and high-resolution design work:

`https://www.dukapilot.com/brand/dukapilot-logo.svg`

JPG for services that do not accept PNG or SVG:

`https://www.dukapilot.com/brand/dukapilot-logo.jpg`

These are stable production URLs served from `www.dukapilot.com`. Do not use a GitHub raw-file URL, local file path, temporary upload, or customer/shop logo as the company logo.

## Source Files

| Format | Repository file | Recommended use |
| --- | --- | --- |
| PNG | `frontend/public/brand/dukapilot-logo.png` | Default public sharing and platform uploads |
| SVG | `frontend/public/brand/dukapilot-logo.svg` | Web, print, presentations, and resizing |
| JPG | `frontend/public/brand/dukapilot-logo.jpg` | Platforms that require JPG |

The application icons remain in `frontend/public/logo/`. The source marketing JPG is also retained in `marketing/brand/` for offline creative work.

## Usage Rules

- Keep the logo square and preserve its aspect ratio.
- Do not stretch, rotate, recolor, crop, or add text over the logo.
- Leave clear space around the mark.
- Prefer PNG on white or transparent-compatible layouts.
- Use SVG when the design may be enlarged.
- Use the official company name `DukaPilot`, owned by Necuva Group Limited.

## Quick Verification

After a production deployment, open the recommended PNG URL in a private browser window. It should load without authentication and return an image rather than an HTML error page.
